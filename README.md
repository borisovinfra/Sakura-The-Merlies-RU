# 🌸 Sakura The Merlies RU

Русский перевод **The Merlies** для Nintendo Switch.

## Совместимость

- **Версия игры:** 1.0.224
- **Title ID:** `0100091028782000`
- Требуется Atmosphère

## Установка

1. Скачайте архив из раздела **Releases**.
2. Распакуйте архив.
3. Скопируйте папку `atmosphere` в корень microSD.
4. Согласитесь на объединение папок.
5. Запустите Atmosphère и затем игру.

## Удаление

Удалите папку:

`atmosphere/contents/0100091028782000/`
