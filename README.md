# 🌸 Sakura The Merlies RU

Полный русский перевод **The Merlies** для Nintendo Switch.

Неофициальный фанатский русификатор в формате **LayeredFS** для **Atmosphère**.

---

## 📌 О проекте

Цель проекта — сделать **The Merlies** полностью доступной на русском языке.

Переведены:

- интерфейс;
- главное меню;
- настройки;
- диалоги;
- игровые подсказки;
- описания;
- внутриигровые тексты.

Перевод протестирован непосредственно на Nintendo Switch.

---

## 🎮 Совместимость

---

## 📦 Установка

1. Скачайте архив из раздела **Releases**.
2. Распакуйте архив.
3. Скопируйте папку `atmosphere` в корень microSD.
4. При необходимости согласитесь на объединение папок.
5. Запустите Atmosphère.
6. Запустите The Merlies.

Итоговый путь файла русификатора:

```text
atmosphere/
└── contents/
    └── 0100091028782000/
        └── romfs/
            └── Data/
                └── resources.assets
```

---

## 🗑 Удаление

Удалите папку:

```text
atmosphere/contents/0100091028782000/
```

После этого игра снова будет использовать оригинальные файлы.
